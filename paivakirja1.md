# Oppimispäiväkirja: Paikallinen git

__Mikä osion tehtävissä oli vaikeaa ja mikä helppoa? Mikä auttoi minua oppimaan? Miten selvitin esteet?__

Aluksi Gitin komentojen käyttäminen oli hieman vaikeaa, koska komentoja oli paljon ja niiden
tarkoituksia oli vaikea muistaa. Erityisesti muutosten peruuttaminen sekä haarojen luominen ja
yhdistäminen tuntuivat haastavilta. Helpointa oli tiedostojen lisääminen, muutosten commitoiminen ja
commit-historian tarkasteleminen.

Minua auttoi oppimaan erityisesti komentojen kokeileminen kaytännössä. Myos virheilmoitukset auttoivat, koska niiden avulla
pystyin selvittämään, mikä meni väärin.

Tarvittaessa kysyin apua ja kokeilin komentoa uudelleen. Harjoittelun avulla
Gitin käytto alkoi tuntua helpommalta.

## Osiossa käyttämäni Git-komennot

| Komento | Kuvaus |
| --------| ------ |
| git init | Luo Git-repositorion |
| git status | Näyttää repositorion tilanteen |
| git add | Lisää tiedoston valmisteltaviin muutoksiin |
| git commit  | Tallentaa muutokset |
| git log  | Näyttää commit-historian |
| git diff | Näyttää muutosten erot |
| git restore | Palauttaa tiedoston aiempaan tilaan |
| git revert | Peruuttaa aiemman commitin tekemällä uuden commitin |
| git tag | Lisää tunnisteen commitille |
| git switch | Vaihtaa haaraa |
| git branch | Näyttää haarat |
| git merge | Yhdistää haaroja |
